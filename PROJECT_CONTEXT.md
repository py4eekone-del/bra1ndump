## Что это
Telegram Mini App — интерактивная визуализация постов с канала @py4e2k0ne. Посты отображаются как плавающие блоки на тёмном фоне, которые можно таскать.

## Структура проекта
```
digital_brain_dump/
├── channel_bot.py      # Бот aiogram - ловит новые посты + показывает кнопку Mini App
├── generator.py        # Генерирует dist/index.html из HTML экспорта Telegram
├── bot.py              # Альтернативный бот (не используется)
├── fetch_history.py    # Загрузка истории через Telethon (требует авторизацию)
├── posts.json          # Сохранённые посты (пока пустой)
├── .env                # Токены (BOT_TOKEN, TELEGRAM_API_ID, TELEGRAM_API_HASH)
├── dist/               # Готовый сайт для деплоя
│   ├── index.html      # Главная страница
│   ├── bg.mp4          # Видео-фон
│   └── photos/         # 39 фоток
└── requirements.txt    # Зависимости
```

## Как добавить новые посты
1. Экспортировать канал через Telegram Desktop
2. Положить экспорт в папку рядом (../ChatExport_YYYY-MM-DD)
3. Обновить путь в `update_posts.py` если нужно
4. Запустить: `python update_posts.py`
5. Запушить на GitHub

## Идеи развития

### Краткосрочные
- **Авто-синхронизация**: Запустить channel_bot.py 24/7 для ловли новых постов
- **Улучшенная сетка**: Начальные позиции по дате (новее = выше)
- **Поиск/фильтр**: Найти посты по ключевому слову

### Долгосрочные
- **Система тегов**: Категоризация постов (#логика, #медитация, #фото)
- **Граф-вью**: Показать связи между связанными постами
- **Режим таймлайна**: Листать посты хронологически
- **Аудио-посты**: Поддержка голосовых сообщений
- **Коллаборация**: Дать пользователям добавлять свои мысли
